# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Instead,
use GitHub's **Security** tab to submit a private vulnerability report to the
repository maintainers.

Include a concise description, the affected file or feature, reproduction steps,
and the potential impact. Please avoid accessing, changing, or retaining data that
does not belong to you while investigating.

The maintainers will acknowledge a report within seven days, keep the reporter
updated as it is assessed, and coordinate disclosure and remediation when the
issue is confirmed. If private vulnerability reporting is unavailable, open an
issue requesting a private contact channel without including vulnerability details.
