Using the data

Every record has a stable id used by its public record page. Legal-status values describe the posture of the cited institution and are not independent verdicts by this project. Source and legal classifications are attributed to that cited institution.

The updated_at field records when a ledger record was last updated; it is not the source publication date or the event date.
